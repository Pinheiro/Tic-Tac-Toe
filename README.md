# Tic-Tac-Toe
The classic game of Tic-Tac-Toe.<br>
The game is played offline from a phone or a desktop using a browser to run the application.<br>
Built with GitHub Copilot.<br>

The user is able to play against an AI opponent and choose one from three levels of difficulty.<br>

The difficulty of the AI opponents are described below:<br>
- Deaf, this opponnet will never lose a game and will apply all possible tricks to win
- Dumb, this opponnet will lose about 50% of its games but it will very seldom make moves to win.
- Blind, this opponnet will place its token on a random place

To play, download a release and open the file source/index.html on your local browser.<br>
