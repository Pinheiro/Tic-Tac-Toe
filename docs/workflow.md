# GitHub Workflow
## initial setup
- create an empty repository for the project  
- rename the main branch to production  
## change control
- create the develop branch from the production branch
- create a feature/*item* for each change from the develop branch
- create a bug-fix/*item* for each change from the develop branch
- merge all feature and bug-fix branches into the develop brach
- test the develop brach
- open a pull-request to merge the develop branch into the production branch
- create a release version
